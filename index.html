Model Release Status Verifier

Paste an AI model release claim. Get a verdict checked against the vendor's own pages — with the evidence quoted.

Try: a new model · a DeepSeek rename · a retired model · a date conflict · an uncovered vendor

What this checks

AI news aggregators, SEO trackers, and vendor marketing all make claims about model releases. This tool checks a claim against the vendor's own pages — the model lists and deprecation schedules that Anthropic, OpenAI, DeepSeek, and Moonshot (Kimi) publish themselves.

confirmed the vendor's own page supports the claim
contradicted the vendor's page shows a different state, or no such model
partial one part confirmed, another uncheckable (e.g. existence yes, release date no)
unverifiable no vendor surface exists for this claim class — a documented gap, not a clean bill of health

What each vendor publishes

Vendors do not publish release dates for most models, so a release-date claim can at most confirm that the model exists. A vendor with no deprecation page (DeepSeek, Kimi) cannot confirm or contradict retirement claims, except where it states a retirement elsewhere in its docs (DeepSeek's model table does, for its legacy Flash names) — the gap is shown, never assumed clean. Every verdict quotes the page it rests on, with the fetch timestamp.

Method

The vendor pages are fetched at build time (multi-transport, per-source deadline) and the resulting model index is baked into this static site. Matching is done entirely in your browser — nothing is sent anywhere. Identifiers are normalized across snapshot suffixes (gpt-4o-2024-05-13 and gpt-4o are the same model family) and family names ("Claude Fable 5" → claude-fable-5).
